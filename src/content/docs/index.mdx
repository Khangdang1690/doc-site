`sqlitedeploy` is an open-source CLI that turns SQLite into a distributed
database for edge and serverless apps. It bundles
[`sqld`](https://github.com/tursodatabase/libsql) (the libSQL server,
MIT-licensed), replicates the WAL to **your own** S3-compatible bucket via
`bottomless`, and opens a public HTTPS endpoint over Cloudflare Tunnel — no
domain, no port-forward, no SaaS subscription.

This very documentation site is powered by sqlitedeploy: the search box
above queries an FTS5 index inside a sqld instance running on Oracle
Cloud's Always Free tier.

## When NOT to use this

- **You need multi-writer.** SQLite is single-writer at the file level. Use
  rqlite, LiteFS Cloud, or Turso's managed product.
- **You need automatic failover.** Recovery is a manual `--sync-from-storage`
  on a fresh primary.
- **You're on Windows.** sqld's WAL implementation is POSIX-only. Use WSL2.
