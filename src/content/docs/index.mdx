## When NOT to use this

- **Multi-writer workloads.** SQLite is single-writer at the file
  level. Use rqlite, LiteFS Cloud, or Turso's managed product.
- **Hard-failover guarantees.** Recovery is a manual
  `--sync-from-storage` on a fresh primary.
- **Native Windows hosts.** sqld's WAL implementation is POSIX-only.
  Use WSL2 or a Linux container.
